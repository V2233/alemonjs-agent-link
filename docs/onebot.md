# OneBot 接入、戳一戳与群管理

启动器默认使用 QQ Bot。配置 `transport: onebot` 可改用已运行的 OneBot v11 服务，通过正向 WebSocket 同时收事件和调用接口。每个实例选择一种连接，不额外登录另一个适配器。

## 配置与启动

先在自己的协议服务中完成账号登录并启用正向 WebSocket，再合并以下配置。占位值需要替换；模型、人格、媒体和记忆配置继续共用。

```yaml
onebot:
  url: 'ws://127.0.0.1:3001'
  selfId: '<机器人QQ号>' # 字符串，必须与实际登录账号一致
  accessToken: '<OneBot访问令牌>' # 本机无令牌服务可省略此项
  master_id: ['<主人QQ号>']
  timeoutMs: 10000
  maxPayloadBytes: 8388608

alemonjs-agent-link:
  transport: 'onebot'
  apiKey: '<模型API密钥>'
  modules:
    settings:
      group-admin:
        groups: ['<授权管理的群号>'] # 默认空列表
```

运行 `agent-link doctor` 检查格式，再运行 `agent-link`。启动器选择内置 OneBot 适配器，不要求 QQ Bot AppID 和密钥。连接、账号或令牌修改后需重启；业务模块配置随下一轮刷新。框架宿主也可将 `alemonjs-agent-link/onebot` 作为平台入口加载，业务入口仍为包主入口。

远程服务需要 WSS 和访问令牌；明文 WS 仅允许回环地址。令牌通过 Authorization 头发送，不进入 URL。连接后先调用 `get_login_info`，账号与 `selfId` 一致才接受事件并报告在线。失败按退避策略重连。`/agentstatus` 的主人私聊视图显示连接状态；在线只证明协议连接，不证明模型和各扩展均可用。

## 消息与戳一戳

已接入私聊、群聊、@、引用编号、图片/音频附件和媒体发送。支持数组消息段与 CQ 字符串输入；输出使用结构化段，普通文字里的 CQ 内容不作为动作执行。发送要求协议成功状态及有效消息编号，失败不算送达。OneBot 使用现有文字分段输出，不使用 QQ Bot 专属原生流接口。

撤回、成员进出、禁言/解禁及部分资料通知进入原有事件上下文；撤回继续取消受影响的待处理回复。通知本身不授予权限。已观察引用沿用本地索引；未观察引用、合并转发的远程展开和平台历史翻页尚未接入。

戳一戳仅接受目标为机器人自己的规范通知，按直接唤醒进入现有队列；同一会话20秒内只处理一次，超过60秒的旧通知不触发。私聊仍受 `privateChatAccess` 限制，群聊仍受聊天权限和请求限流控制。

模型可用 `poke_speaker` 戳当前发言人，不能更换对象，同一会话20秒最多一次，使用 `send_poke`。此方法及群公告属于协议实现的扩展；不支持时返回失败，不伪装成已回戳。停用 `platform` 模块会停止戳一戳触发及工具。

## 群管理

`group-admin` 默认加载但白名单为空。填入授权群后，模型才向已验证主人开放 `manage_group`。自然语言请求需写明对象和内容，例如“将300禁言十秒”；主人私聊还必须明确群号。群聊只能操作当前群。

| 操作        | 协议调用                  | 校验                                         |
| ----------- | ------------------------- | -------------------------------------------- |
| 禁言 / 解禁 | `set_group_ban`           | 秒数1–2592000，解禁固定0；不将 ban 当成拉黑  |
| 踢出        | `set_group_kick`          | 不设置拒绝再次加群                           |
| 专属头衔    | `set_group_special_title` | 机器人必须是群主，最多24字符；空字符串可清除 |
| 群公告      | `_send_group_notice`      | 最多2000字符，需对应协议扩展                 |

适配器每次重新核对当前配置的主人身份、白名单、模块停用状态，并无缓存查询机器人和目标成员身份。角色未知或身份不符时不执行。禁言和踢出不能针对机器人、配置中的主人或群主；机器人为管理员时不能针对其他管理员。只有接口成功回执才返回 confirmed。

操作记录在本机 `platform-actions.sqlite`。同一输入与相同参数再次调用时返回已有结果，不重复发送。超时、断线、异常响应或取消可能发生在平台已执行之后，因此返回 unknown，要求先在平台核查，不自动重试管理操作。明确拒绝返回 rejected。不同输入是新请求，应核查未知结果后再重发。

记录只保留摘要、时间和结果状态，不保存公告全文、令牌或用户原文；默认随 `retentionDays` 清理。群彻底清理也删除对应记录及戳一戳冷却。`/new` 保留记录，避免重置后重复执行旧输入。

## 验证边界

本地真实 WebSocket 测试覆盖账号核验、授权头、消息和失败回执、超时不重试及重连；模型工具到适配器的管理链路，以及独立 CLI / Worker / CBP 启动已有测试。角色变化、冒充主人、跨群、保护对象和头衔权限均有拦截验证。

测试账号、平台操作、模型及回复为本地模拟。真实 QQ 消息、媒体上传、回戳和管理操作仍需实际部署验收。当前不安装或登录协议服务，未接入反向 WebSocket、QQ 空间或全部私有接口。
