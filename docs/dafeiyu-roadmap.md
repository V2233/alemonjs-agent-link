# 能力规划

具体实现状态与待验收项统一维护在[能力建设与验收](capabilities.md)，本页只记录建设顺序与范围。

## 推进顺序

1. **聊天基础**：稳定人设、发言人识别、唤醒和多轮连续性；确保记忆保存、来源核对与删除可信。
2. **媒体闭环**：验证图片、GIF、语音与表情的真实收发、超时和失败回退，再扩展服务适配。
3. **长期陪伴**：完善可纠错记忆、话题续接与心情表达；验证主动消息的订阅、免打扰、次数限制和重启恢复。
4. **管理与扩展**：完善配置、权限、记忆和服务健康管理；验证引用、转发与业务模块。

## 范围与边界

- 社交能力围绕 B 站与 QQ 空间完善，暂不扩展新平台。读取、评论、发布分别核对权限和真实回执。
- 表情能力覆盖收藏、标签、发送、配字与本地管理；QQ 收藏同步依赖网关接口，部署后需要实测。
- 可视化管理按已有能力逐步补齐，不将规划功能标为可用。
- 代码和模拟接口测试不能替代真实模型质量、外部服务与 QQ 收发验收。
