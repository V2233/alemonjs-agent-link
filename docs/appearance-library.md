# 人设形象库

管理页新增「形象库」，按人设保存参考图片，与「生图库」的供应商配置分开。上传静态PNG、JPEG或WebP，原文件最多5MB；解码像素最多1600万，转换后PNG最多8MB，每个人设最多100张。服务解码、按方向旋转、去除原图元数据并保存为PNG。首次上传成为默认图，可手动选择其他默认版本。

数据存于工作空间父目录的`appearances.sqlite`，与既有人设数据同级，不接受用户提供本机路径或任意图片URL。仅管理页可上传、设默认、删除；聊天工具只能访问当前激活人设的图片。

## 聊天行为

`persona_appearance`提供list、show、restyle三个动作。询问长什么样时，模型先查库并发送已有图；可先list选择版本，未指定版本时取默认图。库为空明确提示先上传，不自动重造人物。换装时将库中选定图的实际图片字节作为参考提交编辑。二创保存parentId关联来源，不自动成为默认图，也不覆盖原图。删除有二创后代的原图前，需先删除其二创。

同回合遵守既有图片单次处理与发送队列限制。生成、绘图和形象图共享处理状态；典型人物外貌与换装请求会阻止使用普通无参考图生成/绘图绕过。工具返回queued仅表示排入回复队列，真实平台回执才证明送达。图片选择与意图理解仍依赖模型，尚未实测真实平台投递。

## 参考图编辑

使用现有media.imageGen配置，向兼容的`/images/edits`发送multipart请求，包含model、prompt、image图片字节、size和n=1。参照[OpenAI图像编辑接口](https://developers.openai.com/api/reference/resources/images/methods/edit)。兼容接口不等于已验证每个供应商或模型都支持；当前硅基流动协议不走此接口，未配置、ownerOnly不允许、编辑服务失败时返回失败，不降级为无参考重画，也不调用DSH文本生图冒充二创。

编辑提示要求保持脸型、发色、眼睛、体型和物种特征；模型参考编辑不能保证像素级或绝对一致。原图、二创结果均可管理，真实效果需选定支持图像编辑的模型后验收。用户要更改脸部身份等内容时应明确描述，不能仅凭生成成功宣称完全一致。

本功能不自带未授权的人物图片。先在形象库为人设上传原始形象，再在聊天中询问外貌或要求换装。未修改现有供应商Key、音色或其他人设配置。

验证覆盖静态图片校验、人物隔离、默认图切换、二创来源、重启持久化、删除保护、实际参考字节提交及失败不重试文生图；没有调用真实付费编辑服务，没有浏览器与真实QQ端到端验收。
