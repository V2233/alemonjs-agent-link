# 命令速查

命令都以 `/` 开头（不带斜杠的裸词不会命中），由 AlemonJS 路由器按路径分发；中英文别名指向同一个处理函数。群里的普通文字不走命令，而是走 @、称呼或引用唤醒。

> 本文按代码行为整理。默认值以[配置字段参考](config-reference.md)为准；能力是否经过真实账号验收，见[能力建设与验收](capabilities.md)。

## 权限的三道门

| 身份           | 判定方式                                      | 能做什么                                                                     |
| -------------- | --------------------------------------------- | ---------------------------------------------------------------------------- |
| 普通成员       | 任何群成员、获准的私聊用户                    | 提问、取消自己的请求、查状态与额度、查记忆、看表情、切换人格（群内另有规则） |
| 群管理员或主人 | 平台管理员，或 `master_key` 中的主人          | 开始新话题、取消他人请求、切换本群人格、整理与恢复群记忆                     |
| 机器人主人     | `master_key` 中的账号，且多数管理命令要求私聊 | 模型与密钥、额度调整、工具策略、全局开关、彻底删除数据                       |

`master_key` 通过私聊 `/我是主人` 自助添加：验证码只写入服务端日志，5 分钟内有效、最多尝试 5 次。

## 聊天与会话

| ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------ | ---------------------------------------- |

| `/聊天参考`、`/agentcontext`                                                             | 预览下一次会提供给模型的近期群聊参考                               | 仅群聊，所有成员                         |
| `/聊天参考 清除`、`/agentcontext clear`                                                  | 清除本群近期参考，正式对话与归档保留                               | 仅群聊，管理员或主人                     |
| `/主动搭话 状态\|开启\|关闭\|现在\|暂停 分钟\|恢复`                                      | 管理主人的主动搭话订阅                                             | 仅主人私聊                               |

## 群管理与安全

| 命令                                      | 作用                                                            | 权限                 |
| ----------------------------------------- | --------------------------------------------------------------- | -------------------- |
| `/关闭 原因`                              | 全局停止新的 AI 请求，原因最多 500 字                           | 仅主人               |
| `/开启`                                   | 全局恢复 AI 请求，必须不带参数                                  | 仅主人               |
| `/工具策略`、`/工具策略 状态`             | 查看本群聊天/网页/文件/终端权限                                 | 仅群聊 + 主人        |
| `/工具策略 聊天\|网页\|文件 开启\|关闭`   | 修改本群权限并开始新话题                                        | 仅群聊 + 主人        |
| `/工具策略 终端 开启`                     | 固定回复“终端禁止”，不会开启                                    | 仅群聊 + 主人        |
| `/清除群数据` → `/清除群数据 确认`        | 60 秒内二次确认，删除本群会话、文件、记录、记忆、人格与心情设置 | 仅群聊 + 同一主人    |
| `/清除聊天记录` → `/清除聊天记录 confirm` | 60 秒内二次确认，删除聊天归档，保留记忆与当前对话               | 私聊本人；群内仅主人 |
| `/我是主人`、`/我的主人 验证码`           | 自助申请与校验主人验证码                                        | 仅私聊               |

工具策略重置会终止当前 Worker 并开启新会话，旧权限不会残留。终端对所有身份永久禁止，包括主人。

## 二次确认与不可逆操作

| 操作         | 第一步          | 确认写法                               | 约束                                                  |
| ------------ | --------------- | -------------------------------------- | ----------------------------------------------------- |
| 清空本群数据 | `/清除群数据`   | `/清除群数据 确认`（也接受 `confirm`） | 60 秒内、同一发起人                                   |
| 清空聊天归档 | `/清除聊天记录` | `/清除聊天记录 confirm`                | 60 秒内、同一平台+会话+用户；中文“确认”只重新发起提示 |

以下操作没有二次确认，发送即生效：

- `/忘记全部`、`/忘记群记忆 全部` 立即清空记忆并重置会话。
- `/人格 删除 编号` 删除人格文件，使用它的会话恢复默认。
- `/表情 删除`、`/我的钥匙 私聊 移除`、`/授权记录 移除 编号` 直接移除素材或凭证。
- `/关闭 原因` 立即全局停用 AI，只能由主人 `/开启`。
- `/额度轮转 停用 端点ID` 只影响本次运行，重启按配置恢复。
- `/主动搭话 现在` 会真实发送一条主动消息。

## 实现备注

- **只在私聊注册**：记忆增删、`/主动搭话`、`/语音引擎`、`/模块状态`、`/模型列表`、`/当前模型`、`/额度轮转`、`/密钥配置`、`/移除密钥`、`/我是主人`、`/我的主人`。群里发送不会命中，群记忆请用 `/群记忆`。
- **只在群里注册**：`/聊天参考`、`/聊天参考 清除`、`/工具策略`、`/清除群数据`、`/忘记群记忆`。
- **群内只认主人**：`/工具策略`、`/清除群数据`、`/清除聊天记录`、`/关闭`、`/开启`。
- **会开始新会话**：`/新会话`、`/人格 使用`、`/工具策略 … 开启|关闭`、`/记住`、`/忘记`、`/忘记全部`、`/恢复记忆`、`/忘记群记忆`。
- **不调用模型**：状态、帮助、隐私、额度、密钥、模型池、人格查看/设置、工具策略、聊天参考、清除类、开关类、主人验证、表情管理。例外是 `/整理记忆`（跑一次整理模型）与 `/提问`、`/语音`、`/主动搭话 现在`、`/语音引擎 试听`。
- **兼容写法**：`/工具策略` 也接受 `chat`/`web`/`files`/`terminal` 与 `on`/`off`；`/帮助 密钥` 与 `/帮助 额度` 同文。
- **按钮只填入不发送**：QQ 气泡上的按钮只把指令填进输入框，需要用户自己回车，不会误触执行。
- **@ 与命令不冲突**：群里 @ 机器人后接 `/` 开头的文本会交给命令路由，不会重复触发。
