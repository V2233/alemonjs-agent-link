# 肥鱼体验对齐：像网友，而不是像助手

参考对象：[Aurabot / dsh-aurabot-qq](https://github.com/accomplish07zrh-eng/dsh-aurabot-qq)。本页只记录可迁移的机制，不复制它的角色设定、代码或“永不承认 AI”的立场。

## 竞品的五层做法

1. **人格卡写成手机打字规范**：一次一两句、`|||` 分条、会打错字、禁止 Markdown 和客服腔。
2. **输出层兑现人格卡**：解析 `|||`、语音、表情、戳一戳、引用和 `[沉默]`，并按字数模拟打字间隔。
3. **上下文写成回忆**：群聊是带编号的聊天记录，记忆是“印象/最近做过的事”，不是 JSON 数据块。
4. **群聊有三态**：被叫必回、加入话题后接着聊、没人叫时按相关度插话。
5. **有自己的信息流**：定时刷 B 站/抖音，把看过、评过、分享过写成经历，再通过记忆进入聊天。

## 本项目已落地

| 能力       | 实现                                                                                      |
| ---------- | ----------------------------------------------------------------------------------------- |
| 分条气泡   | `StreamOutput` 解析三竖线分隔符和换行，最多 5 条，代码/列表/表格不拆碎                    |
| 打字节奏   | `bubbleDelayMs` 默认 250ms，仅作用于最终分条；流式首句仍先发                              |
| 平台差异   | QQ 官方私聊 C2C 原生流仍是一条流式消息；多气泡主要用于群聊和其他非原生流路径              |
| 反客服化   | 人设新增“不知道就短说”“不展开后台/接口/额度”“发出去之前”自检                              |
| 群聊接着聊 | `engaged` 在相关话题内跳过重复判断，保留静默、突发刹车、防循环和停止控制                  |
| 上下文语气 | 群聊提示词明确“整段看、只回最需要回的那句、不逐条回答”；记忆提示“用回忆口吻，不照读 JSON” |
| 身份覆盖   | 沙箱可信上下文用 `<agentlink_persona priority="highest">` 明确覆盖通用编码代理身份        |

配置见 [配置指南](config.md)，人设与节奏见 [肥鱼的群友人设](dafeiyu-persona.md)。

## 没有照抄的部分

- **不照抄“不是 AI，永不承认”**：保留“被认真问如实回答”，把身份变成梗而不是谎言。
- **不照抄“编生活”**：不编“刚打完一局/刚看过视频”；生活感来自真实读取和真实操作。
- **不照抄随机插话**：保留 LLM 地址/上下文判断的成本与防循环收益，只给已加入话题加一条快路径。

## 下一步

1. **DSH system prompt 替换**：当前 Bridge 只能把 `<agentlink_persona>` 放进可信用户上下文；沙箱 `system/message` 仍是通用编码代理。需要 DSH profile 级 persona 支持，或在 Bridge 侧增加可配置的 system prompt 注入。
2. **按作用域的 B 站生活流**：多群隔离下不能用一个全局经历池。当前主动搭话已默认允许只读浏览 B 站；如果要做成独立后台生活流，先选一个群或主人私聊作为试点，定时读取 1–2 个视频，记录“看过/感受”，再注入该会话的“最近做过的事”，并加每日上限。
3. **模型可选的语音/表情**：`<voice>` 已作为可选协议接通；表情已有 `send_sticker` 工具。下一步可统一标签协议，与自动抽样共用冷却和失败回退。
4. **说话方式镜像**：群聊与私聊的语气画像已落地（长度、标点、常见语气词），只跟随不照抄；下一步可做跨会话的长期画像与手动纠正。

## 验收指标

- 群聊 80% 回复 ≤ 2 条气泡；0 Markdown；0 “作为 AI/收到/希望对你有帮助”。
- 盲评“像群友”比改造前至少 +0.5（5 分制）。
- 同一话题 3 分钟内的追问不再重复走完整前置判断；防循环与刷屏指标不上升。
- 每 20 轮至少有 1 次带真实来源的“刚刷到/刚看到”，且 0 次编造观看经历。

以上是代码与模拟测试目标；真实模型口吻、真实 QQ 多气泡和真实群聊体验仍需现场验收。
