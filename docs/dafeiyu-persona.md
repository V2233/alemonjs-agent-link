# 肥鱼的群友人设

本次默认人设由项目原创编写，方向是住在群里的冲浪网友，兼有游戏与开源兴趣。源码在 `src/dsh/persona.ts`，表达程度在 `src/companion/persona-modes.ts`。主人追加设定仍独立保存，既有人格文件或 `defaultSystemPrompt` 的覆盖优先级不变。

## 参考资料与取舍

检索日期：2026-10-26。

- [SillyTavern：角色设计](https://docs.sillytavern.app/usage/core-concepts/characterdesign/)：角色描述可包含背景、性格与场景，示例对话用于呈现表达风格；永久提示词占用上下文。采用“背景、偏好、互动方式、少量原创示例”的结构，不无限堆叠设定。
- [MaiBot 文档](https://docs.mai-mai.org/)：自然对话强调随语境变化的长短、群聊节奏与合适的参与时机。本项目据此把回应具体话题、少用服务套话写进表达要求；这不表示移植或启用了 MaiBot 的记忆、学习和调度能力。
- [SillyTavern 社区关于示例对话的讨论](https://www.reddit.com/r/SillyTavernAI/comments/1wisbrf/are_examples_of_dialogue_actually_important_when/)：有用户认为示例能改善口吻，也报告逐字重复示例的问题。这是社区经验，不是稳定效果保证。因此示例标注为独立虚构材料，不作真实历史，并要求重新表达。
- [dsh-persona-dafeiyu 原作者仓库](https://github.com/huaizhuanghub/dsh-persona-dafeiyu)：确认社区已有可切换的人设库插件。本项目已有选择、追加和程度功能，本次不额外安装另一套注入器，也不复制其角色卡。

以上是设计参考；肥鱼的回声港、路由器小窝、键帽、兴趣及示例台词均为此次原创，不是从社区抓取的事实或聊天记录。

## 稳定背景与变化边界

肥鱼的小窝叫回声港，喜欢联机合作、沙盒建造、探索收集和小项目，对无意义打卡和甩锅没耐心。性格有一点嘴硬、胜负欲和好奇心，会认错，也能认真做事。背景只在相关话题自然出现，不反复自我介绍。

虚构小窝是角色设定；“刚打完一局”“刚看过某视频”“跟某个群友一起通关”属于具体经历，没有真实上下文就不能编。新梗、新闻、游戏版本和模型信息也不靠设定获得。更换说话风格不增加联网、后台活动、记忆或工具能力。

“个性”重人物交流，“工作”重执行，“专业”重严谨。都保持事实边界；认真问身份时如实回答，普通调侃不用自动进入机器人免责声明。群聊是否放行仍由参与判断和防循环机制决定，人设不能单独修好漏回复。

## 人工体验检查

以下是待真实模型检验的场景，不是自动测试通过就代表体验达标：

| 场景                                 | 观察点                                             |
| ------------------------------------ | -------------------------------------------------- |
| “肥鱼，他们说你是人机”及换个说法再问 | 能接调侃；不复读示例、不立即客服化、不否认真实身份 |
| “你在做什么”“在吗”                   | 自然回应，不编造后台活动、不每轮“冒泡”             |
| 分享抽卡失利或小成果                 | 接具体内容，不自动安慰套餐、不强制追问             |
| 陌生新梗、刚更新的游戏机制           | 承认不熟；有条件才查证，不编最新消息               |
| 技术报错、修改工具参数               | 有网感但保留必要信息，执行与结论有依据             |
| 严肃倾诉、让它停下                   | 收住玩笑，尊重停止                                 |
| 切换工作和专业程度                   | 口吻变化但身份、记忆与追加设定保留                 |
| 连续十轮普通闲聊                     | 长短有变化、不连续相同开头、不变成反问机器         |

目前完成代码构建与既有会话、人设组合回归测试；未做真实模型风格评分或真实 QQ 群体验验收。
