# AgentLink 工作台

工作台直接提供人设、问答库和额度轮转，首页进入人设。旧管理页面链接会回到首页。产品方向和待建设模块见 [产品模块](product-modules.md)。

## 启动

```sh
npm run build
npm run build --prefix frontend
npm run dev -- --serverPort 17178
```

HTTP 接口由 AlemonJS 框架托管：主应用 `/app/api/admin/*`，插件 `/apps/alemonjs-agent-link/api/admin/*`。前端开发代理指向本机 17178 端口。没有额外管理端口或新增登录流程。

## 日常操作

- 人设：查看、创建、编辑角色与规则，调整表达程度及追加设定；从已记录会话中选择目标，应用角色或恢复默认，同时开始新话题。
- 问答库：按全局或会话查看问答、新增、编辑、删除答案、试验检索结果；试验不增加命中计数，内置问答的修改和删除重启后仍保留。
- 额度轮转：新增、编辑和删除端点，查询余额、测活、启停；编辑轮转规则和本地额度保护。

轮转页面通过专用 `/pool/settings` 接口读取业务数据和提交动作，不再读取、上传或覆盖整份应用配置。服务端只接受端点、轮转规则和额度保护的明确字段；保留密钥脱敏、版本冲突校验、保存前备份和服务端规则校验。收到保存成功不代表模型连接测活成功。

通用配置的读取、校验、保存、历史列表及恢复接口已删除。文件导入导出、任意字段编辑、配置搜索及配置中心菜单也已删除。底层文件写入器仅供业务接口内部持久化使用。

部署配置及历史备份不自动删除；备份仍位于配置目录的 `.agent-link-config-history`，由部署人员管理。平台连接、密钥和路径等初始接入见部署文档，不放入日常工作台。

## 验证

```sh
npm run build
node --test --test-force-exit test/product-settings.test.mjs test/admin-pool.test.mjs
npm run build --prefix frontend
```

测试验证旧通用接口不可访问、专用接口不能修改其他业务、密钥保留、版本冲突，以及人设、问答库和轮转流程。

会话选择器目前汇总问答库记录和人设选择记录，尚未接平台完整群列表；没有记录的会话不会伪造展示。知识编辑保留条目编号并校验更新时间，避免覆盖他人的新修改。
