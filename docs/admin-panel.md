# 后台配置管理

先构建后端及前端，再启用框架 Web 服务：

```sh
npm run build
cd frontend
yarn install
yarn build
cd ..
npm run dev -- --serverPort 17187
```

打开 http://127.0.0.1:17187/app/ ，点击“在线管理”。令牌保存在**实际配置文件目录**的 `.agent-link-admin/token`，每次应用初始化重新生成。不要把令牌放入 URL；页面只在内存中保存令牌。HTTP 端口和监听行为由 AlemonJS 框架管理，配置接口额外要求 Bearer 令牌。

通过 `defineChildren().register()` 返回 `koaRouter`；框架挂载主应用为 `/app/api/admin/*`，插件模式为 `/apps/alemonjs-agent-link/api/admin/*`。静态页面由 `package.json → alemonjs.web.root: dist` 托管。开发前端的 `/api` 统一代理到 `http://127.0.0.1:17187/app/api/`。没有独立 HTTP 服务或额外管理端口。

## 操作流程

1. 输入令牌，读取当前配置。原有密钥显示为占位符，保存时保留真实值。
2. 修改现有字段，或通过“添加配置”新增主配置字段、模型池端点和按群覆盖策略。
3. 查看变更记录，执行“服务端校验”。
4. 点击“校验并保存”，确认后写入实际配置。保存前自动备份，版本变化则拒绝覆盖。
5. 平台连接、路径和进程级参数建议重启后核实。收到“已保存”不代表平台或模型连接测试成功。

在线脱敏配置禁止导出为运行文件，以免占位符被当成真实密钥。需要改变密钥时直接填写新值。移除显式字段后由服务端默认规则处理；没有默认值的必填字段仍会校验失败。

## 历史与诊断

“刷新历史与状态”显示最近 50 条保存前备份、当前进程运行时间和模型池状态快照。恢复备份会先备份当前文件，并检查配置版本。备份位于配置目录的 `.agent-link-config-history`，含完整凭证，文件权限为 0600；当前不自动删除历史文件。

校验复用服务端主配置、模型池、群聊、媒体、OneBot 和模块基础结构校验。模块内部的网络、文件、依赖及平台授权须在实际运行时确认。没有实现模型付费请求测活、完整日志检索或自动重启。

## 验证

```sh
npm run build
node --test test/admin-config.test.mjs
cd frontend
npm run build
```

测试使用临时配置，覆盖脱敏、密钥保留、模型端点删除后的密钥对应、非法配置、版本冲突、备份恢复、Koa 路由鉴权、生命周期失效和非法请求拒绝。
