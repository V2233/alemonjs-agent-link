# AgentLink 文档

AgentLink 把 QQ 群和私聊接成一条受限的 AI 通道：Node 负责编排、状态与安全边界，DSH Worker 负责模型会话与工具。文档按“先跑起来 → 调好 → 守住边界”组织，代码与配置始终是最终依据。

## 文档约定

- **以代码为准**：命令、默认值与权限来自 `src/`；发现文档与行为不一致时，先修文档，再补测试。
- **默认值只写一处**：具体字段的默认值和范围引用[配置字段参考](config-reference.md)，其他页面只讲行为与取舍。
- **区分“已接通”和“已验收”**：[能力建设与验收](capabilities.md)记录真实平台、模型与服务尚未验证的部分，不把代码路径当作线上结果。
- **不展示真实凭证与聊天**：截图和示例只使用占位符；仓库不包含可用的账号、Key、二维码或私聊原文。

## 修改文档

文档与代码同仓库维护。新增命令时同步更新[命令速查](commands.md)；新增配置项时同步更新[配置字段参考](config-reference.md)与[示例](../alemon.config.example.yaml)；新增能力时在[能力建设与验收](capabilities.md)登记状态。
