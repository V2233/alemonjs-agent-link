# 群话题自动积累

## 已接通链路

真人群消息经 `history-capture` 进入 `observeGroupTopics`，不依赖机器人是否回复，并继续调用 `next()`，不截断其他插件。私聊、机器人、机器人自己的消息、命令和超过 1500 字的消息不进入队列；凭据入口在归档入口之前处理。

首次有效群消息自动建立档案，默认允许积累、输出匿名话题和接收相似群话题。未配置标签并不会阻止建档，后台会从讨论学习定位与标签。已有关闭状态不会被消息重开。管理员保存定位与标签后标记为手动档案，自动分析不覆盖其主题，但仍可提炼符合该群设置的话题。

待分析队列位于独立 SQLite 文件，每群最多 20 条，保留一天。每次分析最多读取并确认同一批十条，失败不清空。后台随内置 proactive 模块启动，每分钟检查，每群分析间隔至少五分钟；每次最多分析两个群，进程内防止同根目录并发任务。

后台分析复用工作模型通道，不借用某位群成员的身份或额度。模型输出严格校验结构与长度；仅匿名、通用讨论线索可入库，不将群聊观点写成已验证事实。明确要求模型排除隐私、身份、个人经历、争吵以及转述的机器人/其他群分享，另加敏感模式过滤。模型脱敏不是形式化隐私保证；管理页可删除候选，当前链路不自动外发。

## 公开内容采集

有主题的启用群每小时尝试一次 B 站公开搜索，每轮最多采集一个群。按小时轮换单个标签，避免拼接多个标签导致检索失配。检查前十条结果，只有发布日期为上海时区今天或昨天且标题/简介命中标签的结果才入库。采集期间档案被关闭或改变则放弃结果。

public-video 与 news、human-discussion 分开记录。视频摘要仅是公开标题，并标明未观看、未核实观点；不会伪造热门排名。当前自动来源为 B 站，不代表已接入全网新闻。管理员仍可录入核实后的新闻，手动录入不再是自动积累的前置条件。

## 匹配与记录

相似度采用标签 Jaccard，匹配时检查目标启用、来源输出、目标接收、禁忌、有效期和已分享记录。跨群限制在同平台同机器人内，不回传源群。源群撤权即时影响后续候选查询。

每群保留最近 30 条分析、采集、筛选记录。筛选记录区分日期缺失/过期、主题不匹配、禁忌、重复和入库数量。管理页显示最近结果及可展开历史。群数据清理同时删除档案、队列、源话题与处理记录。

## 管理入口

管理页“群话题库”用于查看、纠正、关闭、删除和预览，不需要手动新增群才能开始工作。支持群档案、权限、来源、候选、处理历史、新闻录入及手动立即采集。

群命令 `/群设置 话题 查看`、`定位 内容`、`标签 游戏,修仙`、`禁忌 内容`、`冒泡/输出/接收 开启或关闭`、`采集`、`候选` 保留。修改要求管理员或主人。`新闻 HTTPS链接 YYYY-MM-DD 标签 摘要` 是人工核实后的公共来源录入。

## 验证及边界

框架测试使用 alemonjs/testing 运行真实归档处理器，验证自动建档、消息去重、机器人排除和事件继续传递。业务测试验证持久化、权限、日期、主题匹配、后台处理与分析中关闭档案。真实工作模型及 B 站网络探测在独立临时目录运行，不向真实群投递。

当前目标是自动积累库，不包括定时向群外发消息。定时发送仍未接通。跨群讨论语义去重、同新闻多 URL 归并仍有限，目前以稳定 ID、源群与摘要归一 hash 去重。进程内并发锁用于现有单模块进程部署，多副本需额外租约机制。部署后无需制造群消息；下一条真实群消息会触发建档。
