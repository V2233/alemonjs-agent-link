# AgentLink 产品方向与功能归属

AgentLink 的日常工作台围绕用户要完成的事情组织：让机器人形成稳定表达、知道该回答什么、在合适的场景参与，并看清额度和执行结果。用户不需要理解配置字段、YAML 路径和服务内部模块名称。

配置中心已移除，不保留“高级配置”替代入口。保留底层部署配置用于启动和环境接入；不删除已有账号、密钥、业务数据或改变已部署的默认行为。

## 从配置项推导产品能力

| 原配置类别 / 代表字段                       | 用户要完成的事情                     | 产品归属和交互                                                                   | 当前状态                                           |
| ------------------------------------------- | ------------------------------------ | -------------------------------------------------------------------------------- | -------------------------------------------------- |
| persona、defaultSystemPrompt、表达程度      | 决定机器人是谁、怎么说话             | 人设：创建、编辑、追加设定、表达程度                                             | 已有独立页面；支持选择已记录会话应用人设与恢复默认 |
| 知识检索、记忆、上下文保留                  | 让机器人知道事实、记住关系和近期话题 | 问答库管理标准答案；长期记忆管理来源和遗忘；会话管理历史与重置                   | 问答库页面已落地；记忆和会话页面待建设             |
| groupChat、groupWakeNames、privateAutoReply | 决定在哪回应、什么时候参与           | 群聊运营：选群后看当前状态，修改活跃程度、兴趣词和唤醒规则；私聊入口处理私聊偏好 | 现有群设置命令继续使用；运营页面待建设             |
| 主动消息和订阅                              | 让机器人在约定的时机主动关怀         | 主动关怀：订阅、暂停、下次执行、执行记录                                         | 现有命令继续使用；页面待建设                       |
| apiKey、modelPool、轮转策略                 | 接入模型并在额度不足或失败时继续服务 | 额度轮转：添加端点、查余额、测活、启停、轮转规则                                 | 已有独立页面，已改为专用业务接口                   |
| 私聊/群聊钥匙、授权和余额                   | 决定谁付费、在哪使用、如何撤销       | 我的钥匙、授权记录：上下文隔离，群管理员管理群副本，提供者管理自己的授权         | 现有聊天命令继续使用；不将个人授权搬进公共后台     |
| budget、输出限制                            | 分配免费额度、控制花费、解释为何暂停 | 额度轮转中的额度保护；未来用量账本展示消耗、待结算和阻断原因                     | 额度保护已有页面；完整账本页面待建设               |
| modules、工具授权                           | 让机器人具备需要的能力               | 能力管理：可用/未就绪/暂停，启停动作和具体失败原因                               | 页面待建设；不把所有模块参数直接生成表单           |
| media、stickers、speech                     | 管理可发送的图片、表情和声音         | 媒体资源：资源预览、上传删除、音色试听、发送结果                                 | 表情已有专用面板；统一媒体页面待建设               |
| transport、账号、路径、Redis、并发、超时    | 完成部署和保障运行                   | 部署文档和运行诊断，普通用户不编辑这些参数                                       | 保留部署层配置；工作台不展示通用编辑器             |

## 交互原则

- 页面围绕业务对象提供动作和结果，先展示真实状态，再给可执行操作。
- 日常使用不要求记字段名或命令：已落地页面直接提供按钮；后续聊天流程优先复用现有按钮及上下文。
- 默认值由服务端决定；表单只暴露有明确业务含义的选择，不复制全部底层参数。
- 人设、知识、长期记忆、近期上下文分别管理。问答库目前是问答检索，不宣称支持任意文档上传或向量检索。
- 每项操作有明确归属：平台连接属于部署方，群运营属于群管理员，个人钥匙与授权记录属于提供者。
- 新页面必须接真实读取与写入流程，包含失败反馈；不放只有标题或模拟数据的导航入口。

## 后续建设顺序

先补齐额度轮转排障和用量账本，再补问答库维护、人设应用与会话选择；随后建设群聊运营、长期记忆与遗忘，最后整合主动关怀、媒体与能力状态。

人设切换需复用会话重置逻辑；记忆删除需复用管理协调逻辑；主动任务需遵守租约与取消规则；额度操作需沿用原子账本和归属校验。不能用文件编辑替代这些业务流程。

## 产品流程与交付标准

产品入口按“对象 → 状态 → 动作 → 结果”设计，不按原配置文件的分组生成页面。以下是建设目标，未接通的能力不视为已交付，也不增加空菜单。

| 产品方向       | 用户进入页面要完成什么                 | 必须形成的业务闭环                                                           | 当前缺口                                                                       |
| -------------- | -------------------------------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| 额度轮转       | 接入供应商，发现耗尽或不可用端点并处理 | 新增连接 → 保存 → 测活与查额 → 主备分配 → 异常筛选 → 编辑或停用 → 复查       | 检测和查额结果目前不是长期历史；需要进一步补失败归因与请求切换记录             |
| 用量与额度保护 | 知道钱花到哪里、为什么停止服务         | 查看今日消耗与待结算 → 查看具体阻断原因 → 调整对应限额 → 后续请求核对        | 当前只有保护规则编辑，不能把限额当剩余额度；账本读取需区分用户、群、门控与全局 |
| 人设           | 让机器人以指定角色参与指定会话         | 创建角色 → 编辑表达与规则 → 应用到会话 → 查看生效角色 → 按原业务规则重置会话 | 已支持角色编辑、已记录会话选择、应用与恢复默认；尚缺平台完整会话名册           |
| 问答库         | 修正机器人对事实的回答                 | 选知识范围 → 添加或修正标准答案 → 试问 → 看匹配结果和来源 → 撤下过期知识     | 已支持新增、编辑、删除和试问；内置内容修改和删除跨重启保留                     |
| 群聊运营       | 决定机器人在哪个群、什么时候说话       | 选群 → 看当前模式 → 调整参与程度和唤醒方式 → 查看生效结果                    | 需要群列表与已有群设置服务对接，避免让用户手填平台和会话编号                   |
| 会话与记忆     | 看清机器人记住了什么并纠错             | 选会话 → 看近期上下文与长期记忆来源 → 重置会话或遗忘指定记忆 → 核对结果      | 需明确近期历史、长期记忆与知识问答的边界，删除不能只删一个文件                 |
| 主动关怀       | 管理订阅和自动触达                     | 创建订阅 → 查看下次执行 → 暂停或取消 → 看执行结果                            | 复用任务租约和取消流程，不能以开关表单代替任务管理                             |
| 能力与媒体     | 使用可用的工具、表情和声音             | 看是否就绪 → 完成接入或选资源 → 预览/试用 → 查看失败原因                     | 复用已有表情面板，逐步补资源操作；平台账号和系统路径仍属部署层                 |

优先补齐额度轮转的排障和用量闭环，再补问答库维护与人设应用到会话，随后建设群聊运营。个人钥匙及群授权有独立归属，不能通过公共工作台越权代改。

## 移除配置中心的边界

- 不保留配置中心菜单、路由、通用 JSON/YAML 编辑器、导入导出或任意字段写入接口。
- 不以“高级设置”“更多参数”重新挂回整份配置；业务表单仅接受所属对象的明确操作。
- 清除从 Yunzai 项目模板遗留的配置、仓库和桌面消息兼容层。AgentLink 页面直接使用框架托管的业务接口。
- 部署必需的配置文件和既有数据保留；内部文件持久化不是面向用户的配置中心。
- 已落地导航仅包含人设、问答库、额度轮转。旧页面地址回到人设首页。

已落地补充：人设页面提供已记录会话选择、当前角色、应用到会话和恢复默认；切换沿用业务重置流程。问答库提供完整新增/编辑/删除及检索验证，保留条目身份与并发冲突检查，内置问答不会因重启覆盖管理员的修改或删除。会话来源目前仅包括知识和人设记录，不等于平台全量会话。
