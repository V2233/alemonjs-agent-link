# 指令、气泡动作与依赖关系

下方原始依赖表保留历史梳理；当前布局规则及本轮全量入口复核见文末，实际权限以处理器为准。

## 阅读说明

- **入口**：`/` 命令；别名写在同一行。
- **作用域/权限**：`群`、`私`、`主`=机器人主人、`管`=群管理员。
- **气泡动作**：该指令发出的卡片上实际出现的可点指令；动态部分用 `${...}` 表示。
- 正文里“提到”某指令不等于按钮；本表只把 `actions` 里的指令算作气泡动作。
- 依赖图部分会同时画“正文引用”和“按钮跳转”，两者含义不同，以第一张表为准。
- 所有可点指令默认只填入输入框，不自动发送。

## 六、依赖关系总结

### 1. 帮助是发现根，但不是所有指令的入口

```text
/帮助
  ├─ /帮助 聊天 ──────────→ /提问、/新会话；返回 /帮助
  ├─ /帮助 记忆 ──────────→ /记忆 或 /群记忆、/记忆检索；返回 /帮助
  ├─ /帮助 人格 ──────────→ /人格、/心情；返回 /帮助
  ├─ /帮助 群设置 ────────→ /群设置；返回 /帮助
  ├─ /帮助 媒体 ──────────→ /语音、/表情；返回 /帮助
  ├─ /帮助 额度 ──────────→ /我的钥匙、私聊 /个人登录；返回 /帮助
  ├─ /帮助 数据 ──────────→ /隐私说明；返回 /帮助
  └─ /帮助 管理 ──────────→ /状态；返回 /帮助
```

`/个人登录` 已从私聊 `/帮助 额度` 详情和 `/我的钥匙` 私聊卡可达，不再只靠文档。

### 2. 钥匙是“额度 → 钥匙 → 授权”的中心链

```text
/额度
  └─ /我的钥匙（群）或 /我的钥匙 私聊
       ├─ 私聊：/个人登录、/我的钥匙 私聊 添加|启用|停用|移除、/授权记录
       ├─ 群聊：/授权钥匙 ${id}
       └─ /个人登录
            ├─ /个人登录 状态|取消
            ├─ /我的钥匙
            ├─ /授权记录
            └─ /个人退出
```

约束：

- `/授权钥匙` 需要目标群管理员，并且本人已有一把群聊钥匙；
- `/授权记录`、`/个人登录`、`/个人退出` 只在本人私聊；
- `/额度` 只展示当前作用域对应的钥匙入口；
- 旧 `/个人密钥`、`/群密钥` 已变成迁移提示，不能再完成绑定；
- `/我的钥匙` 与 `/授权记录` 互相可达，形成有意导航环，但没有自动执行。

### 3. 群设置与人格互相引用

```text
/人格 ──→ /群设置 人设 查看
/群设置 人设 ──→ /群设置 查看
/群设置 帮助 ──→ /群设置 各子命令
/帮助 群设置 ──→ /群设置
```

`/群设置` 是群行为的总开关：强度、静默、唤醒词、禁语、语音、人设、记录、重置都在这里。`/人格` 负责切换人格，群内表达补充则交给 `/群设置 人设`，避免两个入口同时改同一份内容。

### 4. 模型与状态是“状态 → 模型/密钥”的辐射

```text
/状态 ──→ /模型列表、/密钥配置、/额度、/状态 详情、/帮助
/模型列表 ──→ /当前模型、/密钥配置、分页
/当前模型 ──→ /模型列表、/额度轮转、/密钥配置
/额度轮转 ──→ 端点启停/通测、/当前模型、/密钥配置
```

`/状态` 是日常入口；`/模型列表`、`/当前模型`、`/额度轮转` 是主人私聊的深水区。三者都要求私聊主人身份。

### 5. 记忆与清理由“列表 → 条目动作”组成

```text
/记忆 ──→ /记忆检索、/记忆来源 ${id}、/忘记 ${id}
/群记忆 ──→ /记忆来源 ${id}、/恢复记忆 ${id}、/忘记群记忆 ${id}、/过时记忆
```

条目动作依赖列表返回的 `id`；这是动态依赖，不能用固定按钮代替。

### 6. 主动搭话、语音、表情、清除各自闭环

```text
/主动搭话 ──→ 状态 / 开启 / 关闭 / 现在 / 暂停 / 恢复
/语音引擎 ──→ 状态 / 安装 / 试听；失败 → 状态
/表情 ──→ 列表 / 发送 ${id} / 分页 / 帮助
/清除群数据 ──→ 确认 / 取消
```

这些都是低耦合闭环，主要依赖状态存储和平台能力，不依赖其他命令。

## 七、发现的缺口与已做修正

| 缺口                                | 影响                                     | 处理                                     |
| ----------------------------------- | ---------------------------------------- | ---------------------------------------- |
| `/个人登录` 原先不在 `/帮助`        | 只能从钥匙卡或文档发现                   | 已在私聊 `/帮助 额度` 详情补 `登录` 动作 |
| `/授权记录` 不在 `/我的钥匙` 私聊卡 | 登录完成后才容易看到                     | 已在私聊“添加或登录”块补 `授权记录`      |
| `/移除密钥` 无导航按钮              | 删配置后无下一步                         | 已补 `密钥配置`、`当前模型`              |
| `/我的钥匙` 群卡与私卡语义不同      | 群卡只显示群聊钥匙编号；私卡管理两类钥匙 | 卡片标题/说明已区分                      |
| `/个人密钥` 等旧入口仍可触发        | 容易误以为还能绑定                       | 只回迁移提示，按钮指向 `/我的钥匙`       |

## 八、验证建议

1. 在真实 QQ 群里依次点 `/帮助 → 帮助 群设置 → 群设置 查看 → 群设置 记录`，确认每步都有返回路径。
2. 私聊依次点 `/我的钥匙 → 个人登录 → 授权记录`，确认空态和二维码态都有取消/状态。
3. 点 `/额度 → 我的钥匙`，确认群聊和私聊进入不同视图。
4. 对 `/额度轮转`、`/表情`、`/记忆检索` 的动态按钮做一次真机点击，确认 `id`/页码被正确替换。

## 2026-10-30 全量指令布局复核

参考本仓库 `packages/xiuxian-simulator/src/response/message/me/res.ts` 与 `response/shop/handler.ts`：状态优先、条目与操作同块、列表直接展示、底部翻页。明确不采用 `FormatGui` 的固定 bar，也不生成底部键盘。没有新增进度条。

本轮逐一检查 `src/router.ts` 导入的处理器：公共气泡用于全部命令的状态、说明、错误与操作入口；普通 AI 对话、图片、音频及事件监听保持原输出用途，不强制包装成控制台。

| 指令类别                                       | 评估及处理                                                          |
| ---------------------------------------------- | ------------------------------------------------------------------- |
| 帮助、隐私、配置指引、主人验证                 | 保留简短说明；统一正文内入口，精简人格和管理帮助，避免超长          |
| 我的权限、智能程度                             | 身份与作用域置顶；智能、人设、钥匙、管理分组；动作按权限展示        |
| 人设                                           | 每页4字段，字段内编辑/清空/详情；保留完整详情；底部翻页及恢复默认   |
| 人格                                           | 每页6模板；补齐原先超过12项不可翻页的问题；当前模板不重复给使用按钮 |
| 状态、心情、额度、用量、工具策略、群设置       | 保留真实状态与操作作用域，通过公共渲染统一排版，不改变权限和计费    |
| 模型列表、模块状态                             | 移除窄屏表格，改分页条目；刷新保留当前页                            |
