# 大肥鱼与养鱼方案对标复盘

核对日期：2026-10-29。结论：AgentLink 已接通多项养鱼基础链路，仍不能据此宣布体验追平或超过竞品。最明确的实现差距是 B 站画面深读；自主社交的节奏控制值得继续借鉴；聊天自然度和长期陪伴质量缺少双方实际样本。

## 复盘此前建设

方向正确的是把阅读、主观感想、已确认发送分开记录，限制独立阅读工具范围，允许沉默，并让普通用户也能贡献表情素材。这些机制减少假经历、重复分享和只围绕主人运行的问题。

需要纠偏的是用功能清单替代体验结果。多读几条不等于会挑内容，有日记不等于形成连续兴趣，多发表情不等于会接梗；构建、单元测试及模拟接口通过，也不能证明真实 QQ 收发、B 站访问或模型表现。旧能力表存在滞后，应回到当前源码核查，不能把旧待办重复建设一次。

不建议直接照搬固定概率“今天不想看”、因用户没回就“闹脾气”、固定两本日记等外在形式。是否引入这些表现，应由人格一致性和真实体验决定；本轮没有验证它们会改善陪伴质量。

## 后续优先级与验收

1. **视频深读**：为无字幕、硬字幕、演示类内容提供有限帧证据。只有实际返回并交给视觉模型的帧才计入观察；元数据、抽帧失败和未采样片段不得补写。实测平台访问、取消、体积/次数预算与视觉成本。
2. **社交节奏与连续兴趣**：对照“接短句、等特定人、退出他人定向对话、隔天续题、收到纠正”这些完整过程，补有证据的等待/续接机制。增加自主性前保留会话隔离、停用和次数控制。
3. **实际质量采样**：使用[回复质量对照](companion-benchmark.md)的相同场景记录双方原始回复、沉默和媒体表现，尽量控制模型与输入；自然度、连续性、证据一致性分别评审，同时记录延迟、费用和覆盖量。没有采样保持待评。
4. **长程与管理验收**：连续跨日检查作息、偏好修正、重复分享、重启与退订，再走一遍管理界面的配置、运行状态和故障定位。源码有入口与用户能完成操作分别验收。

### 同日后续：画面读取实现进展

上述差距表记录初次复盘时的状态。后续已接通可选 `visualRead`：下载受限大小的单段 MP4、ffmpeg 在三个位置采样、调用独立视觉服务，并返回采样位置与证据范围。默认关闭，详细配置与失败边界见[模块说明](modules.md)。这缩小了画面读取的实现差距，尚未证明真实 B 站访问、视觉识别质量或整体体验达到竞品水平；音频理解、无字幕转写和长程对照仍未完成。

### 同日后续：多发言人续接

已将群聊最近一次问答改为按平台和发言人分别保留两分钟，交错对话不再互相覆盖；选择引用回复时按实际接话消息归属保存，结束、取消与上下文失效后防止迟到结果重开旧续接。这改善了收到消息后的会话连续性，仍不等同于 qq-bridge 二代的自主长轮询和唤醒工具协议。

### 同日后续：模型选择等待条件

已接入 `set_group_wait`，模型可在当前群等待本批已知发言人，附加字面关键词和 15–300 秒期限；无关普通消息期间不额外调用模型，明确呼唤可打断，命中后仍按普通参与规则判断。此项补上了事件驱动的选择性等待，不含历史消息长轮询、无人发言时的定时唤醒或跨重启恢复，不能宣称完整复现竞品二代协议。

### 同日后续：有回执的本地消息收件箱

已增加当前群、当前机器人隔离的消息收件箱，模型可顺序读取近期归档、固定快照翻页、凭实际读取回执确认进度。读取后新到的消息不会被同一次确认清掉，进度跨重启保留，历史删除会使旧回执失效。这补上了主动检查近期背景的读取协议；与 QQ 平台未读分开，也不等同于远端历史长轮询或定时唤醒。

### 同日后续：基础人设实采

已增加可复现的实际模型文字采样入口，并保留两轮12题的原始结果与提示快照。根据具体样本修正了评论背书、将未返回误说成内容为空、照抄内部发送状态等表达。复测仍有截断、暗示亲历和过度承诺反例；这是基础人设的小样本观察，不是完整产品或竞品对照，详见[采样复盘](companion-sampling-review.md)。
