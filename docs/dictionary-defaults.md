# 热词词典默认数据

- [新华报业网：京东消费观察，2026 上半年热梗、情绪与消费行为研究](https://www.xhby.net/content/s6a696efce4b03d9ce79721d1.html)（2026-07-29）：爱你老己、老来得己、前额叶友好、大脑降噪、人生奥德赛时期、背手负鼠、哭哭马、低电量人生、手搓一切、我见识到自己的厉害了。

默认数据在 `src/dictionary/defaults.ts`。打开词典数据库时执行带事务的一次性版本迁移，新安装和升级安装均补缺项；同名管理员词条不覆盖，停用状态保留。迁移完成后编辑、删除的词条不会在重启时恢复。未修改正在运行进程的数据库；部署新代码后初始化词典存储时生效。
