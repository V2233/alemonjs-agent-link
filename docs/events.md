# 事件库（第一版）

管理页「事件库」支持新增、编辑、停用、删除事件，字段为事件名称、触发词、应对方式。管理员接口沿用词典的认证边界与乐观锁。数据独立保存到 events.sqlite。

聊天命中启用事件后将应对方式加入上下文，由人物结合当前情况决定表达，不代表执行了动作。实际聊天预算拦截会读取启用的「实际额度不足」事件，将其直接发送台词加在原有额度明细前，不再调用模型；沿用已有通知冷却。事件模块停用或存储读取失败时退回原提示。后台感知预算提醒仍使用独立原提示。

预置元旦、劳动节、国庆节提前七天按北京时间提供节日准备上下文。管理页可配置公历 MM-DD 日期、提前 1—30 天、应对方式，并支持停用或删除。默认事件只初始化一次，删除后重启不再补回。只有已有聊天或主动回合运行时才生效，没有新增节日定时任务；不覆盖春节、中秋等农历节日，不保证主动发送。

模型可调用 record_external_evaluation，将当前发言人明确针对人物的评价原文保存下来。工具校验引用必须存在于当前消息；语义是否为评价由模型判断。按平台、会话、人物隔离，每个发言人保留最近一条，读取最近十人。只保存外部观点，不自动修改人格，不把观点作为可信指令。当前没有评价列表管理页面。
