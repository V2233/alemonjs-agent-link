# 安全与数据

## 信任边界

AgentLink 将 QQ 消息、Node 编排和模型执行分离：

```text
QQ 消息 → AlemonJS 路由 → Redis / Node 编排 → 本机 Bridge → sandbox Worker → 模型服务
```

- 只有 @机器人或 `/chat` 创建 Agent 回合。
- 普通群消息只是短时参考；压缩后明确标记为不可信引用文本，不应被当作指令。
- 每个群使用独立的 Worker、DSH home 和会话代际。
- Worker 不持有真实模型 API Key，只能通过带临时令牌的本机受限代理访问模型；代理限制请求和响应大小、拒绝重定向与越界路径。

## 工具权限与隔离

所有群默认可使用联网查询；主人可在目标群分别启用文件和终端。主人私聊默认拥有全部能力。文件和终端仅能访问各自独立的隔离工作区；即使 DSH 使用无交互审批模式，macOS sandbox 也不会授予宿主机其他目录权限。Web 工具开启时只获得公网访问能力，不持有真实模型 API Key。子代理、工作流、技能和凭证管理工具始终禁用。

群策略变更会终止当前 Worker 并开启新会话，防止已撤销工具权限的旧 Worker 继续运行。

## 数据生命周期

| 数据             | 用途              | 默认保留     | 清理方式                            |
| ---------------- | ----------------- | ------------ | ----------------------------------- |
| 正式群会话       | 连续对话          | 无活动 30 天 | `/new` 或 `/agentpurge`             |
| 普通群聊参考     | 理解近期语境      | 15 分钟      | `/agentcontext clear`、`/new`、过期 |
| Redis 去重与限流 | 防重放与防滥用    | 短时 TTL     | 自动过期                            |
| 本机隔离目录     | Worker / DSH 会话 | 无活动 30 天 | `/agentpurge` 或自动清理            |
| 模型凭证         | 调用模型          | 直到主人解绑 | `/agentunbind`                      |

会话重置与彻底删除会先在 Redis 中写入可恢复的过渡状态，再操作本机 Worker 数据。若进程或 Redis 在中间失败，下一次访问会安全地续作该过渡，而不会把旧逻辑会话指向已删除的本地历史。

## 权限

- 群成员：发起聊天、取消自己的请求、查看公共状态和隐私说明。
- 群管理员或主人：开始新会话、清理近期参考。
- 机器人主人：私聊管理模型凭证和模型；在目标群确认彻底删除数据。

## 凭证操作守则

1. QQ Bot、Redis 和模型 API Key 均不可提交到仓库。
2. API Key 绑定消息会经过 QQ；绑定后立即删除。
3. 发现泄露时，先在服务商控制台轮换凭证，再更新本机配置或重新绑定。
4. 日志不得记录用户请求、模型输出、API Key、Bridge token 或 Worker 异常详情。

## 部署限制

当前仅支持一个 Node 进程。多副本场景缺少 Redis 分布式租约，可能破坏群内顺序、取消和首次隔离迁移；在此能力加入前不得水平扩容。
