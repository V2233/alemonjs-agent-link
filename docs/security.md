# 安全与数据

## 信任边界

AgentLink 将 QQ 消息、Node 编排和模型执行分离：

```text
QQ 消息 → AlemonJS 路由 → 本地状态库或 Redis / Node 编排 → 本机 Bridge → sandbox Worker → 模型服务
```

- 群聊通过 @、称呼、引用机器人或 `/chat` 唤醒，也可按相关度与限额主动参与。`groupChat.enabled: false` 关闭自主参与；开放的私聊默认也响应普通文字。
- 私聊按平台和用户隔离，普通用户开放后默认具备聊天、联网查询和受限个人目录文件操作能力，终端始终禁止。纯聊天私聊历史默认保存 10 轮、最多 24 小时，可用 `/new` 清空；仅在完整回复收到平台成功回执后保存；平台接收不代表用户已读。
- 群聊消息段、引用和转发内容都标记为引用资料，不应被当作工具授权。批次的工具身份取自实际选中的发起者：显式命令优先，同优先级取最后一位；选择引用回复对象不会改变工具身份。
- 每个群使用独立的 Worker、DSH home 和会话代际。
- Worker 不持有真实模型 API Key，只能通过带临时令牌的本机受限代理访问模型；代理限制请求和响应大小、拒绝重定向与越界路径。

## 工具权限与隔离

所有可聊天用户默认可联网查询及操作当前会话的受限文件目录。目录规划为 `workspaceRoot/scoped-files/{groups|users}/<会话哈希>/<平台、机器人和群或用户身份哈希>/`，所有哈希由服务端真实会话身份计算，不接受模型指定身份或根路径。群成员共享当前群目录；个人目录不与群共享，平台与机器人之间也隔离。

文件操作仅由 Node 的 `workspace_*` 工具提供，支持 UTF-8 文本读写、列目录、建目录、文件重命名和删除文件／空目录。路径仅允许目录内相对路径，拒绝路径穿越、绝对路径、符号链接、硬链接与特殊文件；覆盖已有文件需显式 `overwrite`，不支持递归删除。单文件最多 256 KiB，每个分配目录最多 10 MiB、1000 个条目，路径最多16层。服务串行同步校验并执行文件操作；部署仍只允许一个 Node 进程，宿主运维不得把这些目录交给其他不可信程序写入。

终端对所有身份始终禁止，包括主人；旧策略中的终端权限不再生效，命令不能重新开启。DSH 原生文件、文件搜索、终端及后台作业工具固定禁用，DSH 进程不挂载这套文件目录。必要时通过已绑定会话的 framework MCP 调用相同的受限工具。OS 沙箱仍保护 DSH 执行环境，但其运行库读取权限不是文件工具的用户权限。

策略版本 1 升级为版本 2 时，启用新的受限文件能力，保留聊天和网页开关并关闭终端；之后主人通过 `/工具策略 文件 关闭` 保存的版本 2 禁用设置会保留。`/new` 保留会话文件；彻底清除群数据及现有过期清理流程会一并删除对应文件。普通用户私聊准入由 `privateChatAccess` 控制，默认 `all` 向普通用户开放，可改为 `owner`；仍受额度和个人目录隔离限制。

子代理、工作流、技能和凭证管理工具仍禁用。

Linux Worker 为了访问本机 Bridge 的回环代理而保留网络命名空间；Bubblewrap 负责文件、进程、IPC 和 UTS 隔离。生产 Linux 宿主或容器应以防火墙、网络策略或容器网络限制 Worker 的额外出站访问。

群策略变更会终止当前 Worker 并开启新会话，防止已撤销工具权限的旧 Worker 继续运行。

## 默认开放的能力

除终端和跨工作目录访问外，默认开放聊天、网页、会话文件、主动搭话、自动表达、表情自动收集、B 站阅读/评论、QQ 空间读取/发布/互动、群管理和本地面板。群管理仍只接受已验证主人，并由适配器再次核对平台权限。边界没有放宽：

- 文件工具仍只允许当前会话目录内的相对路径，拒绝路径穿越、绝对路径、符号链接、硬链接和特殊文件；不能切换群或用户目录。
- 终端对所有身份始终禁止，配置或策略不能重新开启。
- 表情自动收集会把启用范围内的图片交给配置的 `media.vision` 审核；未配置视觉服务时只收平台标记的表情。主人可用 `autoCollect: false` 关闭。
- `autoQQSync` 默认开启，会把自动收藏写入机器人号 QQ 收藏（平台侧不可逆）；可用 `autoQQSync: false` 关闭。
- B 站评论和 QQ 空间发布默认 `dryRun: false`，只有主人本轮明确要求时才会真正执行，并受每日次数和冷却限制；改 `dryRun: true` 可只预览。
- 多 Key 端点池的 Key 保存在配置或 `apiKeyEnv` 指向的环境变量中；日志和管理命令只暴露端点 id，不返回 Key。轮转只应使用自己有权使用的 Key，并遵守服务商条款。

## 本地表情面板

可选的表情面板默认开启，但只绑定 `127.0.0.1` 或 `::1`；未配置 token 时首次启动自动生成 64 位十六进制 token 并写入数据目录（权限 600），所有接口（含图片）都校验 token，并限制请求体 8 MiB、单图 5 MiB。面板不提供跨域头、不返回素材绝对路径，删除只移除清单条目。token 会出现在浏览器地址栏和图片 URL 中，只应在可信本机使用；面板没有 TLS，禁止把监听地址改成公网地址。

## 数据生命周期

| 数据             | 用途              | 默认保留     | 清理方式                            |
| ---------------- | ----------------- | ------------ | ----------------------------------- |
| 正式群会话       | 连续对话          | 无活动 30 天 | `/new` 或 `/agentpurge`             |
| 普通群聊参考     | 理解近期语境      | 15 分钟      | `/agentcontext clear`、`/new`、过期 |
| 状态库去重与限流 | 防重放与防滥用    | 短时 TTL     | 自动过期                            |
| 本机隔离目录     | Worker / DSH 会话 | 无活动 30 天 | `/agentpurge` 或自动清理            |
| 问答库与提问日志 | “为什么”类问答    | 无活动 30 天 | `/清除群数据` 或自动清理            |
| 模型凭证         | 调用模型          | 直到配置移除 | `alemon.config.yaml` 由运维管理     |

会话重置与彻底删除会先在状态库中写入可恢复的过渡状态，再操作本机 Worker 数据。若进程或状态库在中间失败，下一次访问会安全地续作该过渡，而不会把旧逻辑会话指向已删除的本地历史。

## 权限

- 群成员：发起聊天、取消自己的请求、查看公共状态和隐私说明。
- 群管理员或主人：开始新会话、清理近期参考。
- 机器人主人：私聊管理模型凭证和模型；在目标群确认彻底删除数据。

## 凭证操作守则

1. QQ Bot、Redis 和模型 API Key 均不可提交到仓库。
2. API Key 绑定消息会经过 QQ；绑定后立即删除。
3. 发现泄露时，先在服务商控制台轮换凭证，再更新本机配置或重新绑定。
4. 日志不得记录用户请求、模型输出、API Key、Bridge token 或 Worker 异常详情。
5. 模型 API Key 存放在 `alemon.config.yaml` 的 `alemonjs-agent-link.apiKey`。该文件必须仅对运行账户可读、保持 Git 忽略，且不能复制到日志、镜像或公开位置。

## 部署限制

当前仅支持一个 Node 进程。多副本场景缺少 Redis 分布式租约，可能破坏群内顺序、取消和首次隔离迁移；在此能力加入前不得水平扩容。

## 私聊个人 Key

个人 DeepSeek Key 与共享机器人凭证分开：Redis 只保存 AES-256-GCM 密文和启停状态，加密主密钥保存于本机 `.data/agent-link/personal-key.key`（新文件权限 0600），迁移需同时备份两者。管理指令仅限本人私聊，应用归档和引用屏蔽其内容，不会更改全局机器人凭证。工作区仅通过当次受认证的本机 Bridge 内存使用 Key，不写入 Worker 环境或文件。详见 [个人 Key 管理](personal-key.md)。
